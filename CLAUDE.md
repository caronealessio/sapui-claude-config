# Regole generali (tutti i progetti)

Prima di ogni modifica al codice, anche minima, leggi per intero la skill `coding-guidelines` e, nei progetti SAPUI5/Fiori/CAP, chiama il tool `get_guidelines` del server MCP `sapui5` e leggi tutto il risultato.

Riepilogo: codice in inglese; variabili in Hungarian notation (`sName`, `oModel`, `aItems`, ...); ogni metodo con firma e breve spiegazione (JSDoc); commenti e testi in italiano, salvo richiesta esplicita diversa dell'utente.
